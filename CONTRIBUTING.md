# Contributing

Thanks for your interest in contributing to Aapda-Vision-AI. Please follow these guidelines:

1. Fork the repository and create a topic branch for your changes.
2. Keep changes small and focused; open pull requests against `main`.
3. Run tests and linters before submitting a PR.
4. Do not commit large model files or datasets. See `docs/release-notes.md` for large-file handling.
5. Include descriptive commit messages and PR descriptions.

If you want help packaging models or test data, open an issue and we'll coordinate.
